# Spatial Science and Urban Systems — lab website

The SSUS lab website, built with Hugo and served by GitHub Pages. A push
to `main` triggers [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml),
which builds the site and deploys it; nothing built is committed.

- Lab: https://github.com/ssus-lab
- Site: https://spatialscience.org

## Preview locally

```sh
hugo server
```
